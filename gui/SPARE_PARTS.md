# Spare parts

Zed crates and components that are unhooked, or slated to be unhooked, from the
obake app (not initialized, not built as part of `zed`) but kept in the tree because
they look reusable. Entries marked "pending" are still hooked in.
Add an entry whenever something useful gets unhooked, so it isn't forgotten.

Format: crate (or file) — what it is — possible obake use — how it was unhooked.

- **project_panel** — tree view of a project with file operations, drag and drop,
  multi-select — browser for runs, recordings, traces — (pending second pass)
- **search** — buffer and project search bar, query options, match navigation —
  searching traces and logs — (pending second pass)
- **outline** — fuzzy picker over a document's symbols — jump to a frame or an event
  — (pending second pass)
